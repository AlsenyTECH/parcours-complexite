Module 1

Mesurer un algorithme

Opérations élémentaires, taille de l'entrée, pire, meilleur et moyen cas.

1

Comprendre. Lis, regarde la vidéo, fais tourner l'algorithme dans l'animateur.

2

Démontrer. Refais chaque calcul sur une feuille avant d'ouvrir la correction.

3

Implémenter. Code l'algorithme dans la page, les tests vérifient, la mesure trace ce qu'il coûte vraiment.

4

S'exercer. Exercices gradués, puis le test de sortie qui valide l'étape.
